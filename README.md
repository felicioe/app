# App e Site de Consultoria

Este repositório será usado para o desenvolvimento do aplicativo e site da consultoria.

## Objetivo

Centralizar o código do projeto, facilitar a colaboração e manter a estrutura do desenvolvimento organizada.

## Estrutura inicial

- `README.md` — documentação principal do projeto
- `.gitignore` — arquivos e pastas que não devem entrar no controle de versão

## Próximos passos

- definir a stack tecnológica
- criar a estrutura inicial do app
- desenvolver as telas e funcionalidades
- configurar deploy e ambiente de produção

## Como contribuir

1. Clone o repositório
2. Crie uma branch para sua funcionalidade
3. Faça as alterações
4. Commit e push
5. Abra um pull request
